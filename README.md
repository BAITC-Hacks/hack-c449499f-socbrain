# SOCBrain

Хакатонный проект: система автопротоколирования совещаний с фиксацией поручений.

## Задача

Секретарь записывает совещание, участники получают уведомление о записи и транскрибации. Система преобразует речь в текст, готовит проект протокола и выделяет поручения, сроки и ответственных. Секретарь проверяет и утверждает результат перед публикацией.

## Планируемый сценарий

1. Создать совещание и указать участников.
2. Получить согласие и включить запись либо загрузить готовый аудиофайл.
3. Получить транскрипт с временными отметками.
4. Сформировать проект протокола и список поручений.
5. Проверить цитаты, ответственных и сроки вручную; исправить ошибки распознавания.
6. Утвердить протокол и отслеживать исполнение поручений.

## Принципы обработки

- Каждое извлечённое поручение должно быть связано с фрагментом транскрипта.
- Неопределённые ответственные и сроки отмечаются для проверки, а не угадываются.
- Аудиозапись и протокол доступны только уполномоченным участникам.
- Ключи API хранятся в переменных окружения и не добавляются в Git.

## Статус

Репозиторий находится в разработке. Команды установки и запуска будут добавлены вместе с исходным кодом. Этот README описывает целевой сценарий, а не заявляет о готовности функций.
