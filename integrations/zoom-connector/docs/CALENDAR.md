# Календарь Zoom

`ZOOM_USER_IDS` содержит ID или email пользователей через запятую. Worker обновляет календарь сразу
после запуска и далее раз в `CALENDAR_POLL_SECONDS` (минимум 30 секунд).

Для каждого пользователя объединяются два официальных списка:

- `/users/{userId}/meetings?type=upcoming_meetings` — запланированные встречи организатора;
- `/users/{userId}/upcoming_meetings` — встречи ближайших 24 часов, включая приглашения.

Дубли объединяются по UUID/occurrence, в `calendar_sources` остаются источники `hosted` и `invited`.
Кеш заменяется транзакционно: если Zoom временно недоступен, предыдущий успешный кеш сохраняется.

Приглашения из Outlook/Exchange, Google Calendar или iCloud появляются во втором API только когда
для пользователя включена **Calendar and Contacts Integration** в Zoom web portal. Это не прямой
коннектор к Microsoft Graph или Google Calendar: Zoom остаётся источником нормализованного расписания.

Календарь помогает показать предстоящие совещания и сопоставить title/date с RTMS. Само подключение
RTMS запускается событиями Zoom, а не локальным таймером; это устраняет подключение по устаревшему кешу.
